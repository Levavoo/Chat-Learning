## Study workflow

1. Read the lesson's mental model and make a prediction.
2. Run commands only in a disposable practice repository.
3. Inspect `git status`, `git log --oneline --graph`, and `git remote -v` where appropriate.
4. Record what changed locally or on GitHub, then complete the exercise.
