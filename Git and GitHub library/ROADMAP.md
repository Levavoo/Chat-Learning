# Git and GitHub Roadmap

## Phase 1 — Work locally

- [ ] Initialize a repository, inspect status and create commits.
- [ ] Explain staging versus working-tree changes and commit history.
- [ ] Read diffs and use `.gitignore` correctly.

## Phase 2 — Branch and synchronize

- [ ] Create, switch and merge branches.
- [ ] Explain clone, fetch, pull, push, remotes and tracking branches.
- [ ] Resolve a conflict in a practice repository.

## Phase 3 — Collaborate with GitHub

- [ ] Distinguish fork from clone.
- [ ] Create a pull request and review the diff.
- [ ] Understand issues, permissions and branch policies.

## Phase 4 — Automate safely

- [ ] Explain workflow, job, runner, event and step.
- [ ] Create a minimal CI workflow for a practice repository.
- [ ] Keep secrets out of logs and use least-privilege permissions.

## Milestone

Demonstrate the complete journey from editing a Markdown file through a reviewed pull request into main, then pull the update to a second local clone.
