- build command-line tools

## Key concepts

### CLI tools
Run scripts with arguments from terminal

### APIs
Fetch data over HTTP (JSON)

### Scraping
Extract data from websites

### Database
Store structured persistent data

---

## Common mistakes

- not handling API errors
- ignoring rate limits
- scraping without checking legality
- not closing DB connections
- writing scripts without structure
