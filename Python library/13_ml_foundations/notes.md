## Key concepts

### Features (X) vs Target (y)
- X → input variables
- y → output (label)

### Train/Test Split
- train → learn patterns
- test → evaluate performance

### Overfitting
- model learns noise

### Underfitting
- model too simple

---

## Common mistakes

- training and testing on same data
- not scaling features
- ignoring evaluation metrics
- misunderstanding accuracy vs real performance
