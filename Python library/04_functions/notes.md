---

## Key concepts

### Function = reusable block of code

### Return vs print
- `print()` → shows output
- `return` → gives value back

### Lambda
- small, one-line function
- often used with `key=`, `map()`, `filter()`

### Key function
- defines how something is compared (e.g. sorting)

---

## Common mistakes

- forgetting `return`
- modifying global variables unintentionally
- using lambda for complex logic
- confusing `print` with `return`
- mutable default arguments (important later)
