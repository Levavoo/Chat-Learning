# Object-Oriented Programming (OOP)

## Goal
Model real-world concepts using classes and objects.

---

## Topics
- classes and objects
- attributes (instance vs class)
- methods
- constructors (__init__)
- inheritance
- polymorphism
- dunder methods
- dataclasses
- property / staticmethod / classmethod

---

## What you should know after this section

- create and use classes
- understand how objects store state
- use inheritance to reuse code
- override behavior (polymorphism)
- use special methods (__str__, __repr__, etc.)
- write cleaner and more structured code

---

## Key concepts

### Class vs Object
- class → blueprint
- object → instance of class

### self
- refers to the current instance

### Constructor
- `__init__` initializes object

### Inheritance
- reuse behavior from parent class

---

## Common mistakes

- forgetting `self`
- modifying class attributes unintentionally
- overusing inheritance
- not understanding instance vs class variables
