# Python Reference Repository

A structured repository to learn, practice, and reference Python from beginner to advanced topics, with a clear path toward data analysis and machine learning.

---

## Purpose

This repository is designed to:

* Provide **clear, minimal examples** for every important Python concept
* Serve as a **quick lookup reference**
* Reinforce understanding through **hands-on practice**
* Build a solid foundation for **data science and machine learning**

---

## Structure

The repository is organized into progressive sections:

```
01_fundamentals/
02_control_flow/
03_data_structures/
04_functions/
05_error_handling/
06_files_and_modules/
07_oop/
08_intermediate_python/
09_advanced_python/
10_testing_and_quality/
11_real_world_python/
12_data_python/
13_ml_foundations/
14_advanced_ml_path/
```

Each section contains:

* `.py` files → focused examples
* `.ipynb` files → data / ML topics
* `notes.md` → explanations and key concepts
* `exercises/` → practice tasks

---

## File Format (Important)

Each example file follows a consistent structure:

```python
"""
Topic: Example Name
Goal: What this teaches
Level: Beginner / Intermediate / Advanced
"""

# 1. Basic example
# 2. Common usage
# 3. Important notes
# 4. Pitfalls
# 5. Output (as comments)
```

---

## How to Use This Repository

1. Open one topic folder
2. Read the notes
3. Run the example files
4. Modify the code
5. Solve the exercises
6. Move to the next topic

---

## Learning Rules

* One concept per file
* Always run code, don’t just read
* Break things intentionally
* Rewrite from memory
* Focus on understanding, not memorizing

---

## Recommended Workflow

For each topic:

1. Read example
2. Run it
3. Rewrite it without looking
4. Change inputs and observe behavior
5. Solve exercises
6. Apply in a mini project
