## Key concepts

### Mutable vs Immutable
- Mutable: list, dict, set
- Immutable: tuple, str

### When to use what

- list → ordered, changeable
- tuple → ordered, fixed data
- set → unique values only
- dict → key-value mapping

---

## Common mistakes

- modifying a list while iterating
- using lists when dict would be better
- forgetting that sets remove duplicates
- accessing dict keys that don’t exist
- shallow vs deep copy issues
