# Tuples

> **Core idea:** Store an ordered immutable collection.

## Learning objectives

- Explain why the technique exists and identify where it is useful.

- Recognize the main pitfall and solve a variation independently.

## Concept and motivation

**Tuples** is part of the broader topic **Data Structures**. Store an ordered immutable collection. Think of it as a tool for expressing a particular operation clearly rather than syntax to memorize. When reading an implementation, ask: *What information goes in? What operation happens? What result or side effect comes out?*
