## How to study

1. Read one learnpaper and write an explanation in your own words.
2. Predict its example, then run the linked code and inspect its output.
3. Change the inputs and test a nontrivial boundary case.
4. Complete the paper's independent practice task.
5. Review concepts until you can recreate the program without copying.

## Chapter-level task
