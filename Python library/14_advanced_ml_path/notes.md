## Key concepts

### Feature Engineering
Transform raw data into better inputs for models

### Pipeline
Chain preprocessing + model into one workflow

### Imbalanced Data
When one class dominates (e.g. fraud detection)

### Hyperparameter Tuning
Optimize model settings

### Ensemble Models
Combine multiple models (Random Forest, Boosting)

---

## Common mistakes

- data leakage (very important)
- tuning on test set
- ignoring baseline models
- overcomplicating models too early
- not validating properly
