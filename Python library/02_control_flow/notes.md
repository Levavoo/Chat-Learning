# Control Flow

## Goal
Control how a program executes using conditions, loops, and logical structures.

---

## Topics
- if / elif / else
- match-case (Python 3.10+)
- for loops
- while loops
- break / continue / pass
- list comprehensions

---

## What you should know after this section

- write conditional logic
- loop over lists, strings, and dictionaries
- control loop execution
- write compact expressions using comprehensions

---

## Common mistakes

- forgetting indentation
- infinite while loops
- using = instead of ==
- modifying a list while iterating over it
- misunderstanding loop conditions
