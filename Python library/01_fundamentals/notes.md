# Fundamentals

## Goal
Build a solid understanding of basic Python syntax, core data types, input/output, and simple operations.

## Topics
- Variables
- Basic data types
- Strings
- Numbers
- Booleans
- Input / output
- Type casting

## Rules for this section
- Run every file
- Change values and re-run
- Read the comments
- Notice the output
- Try small variations yourself

## What you should know after this section
You should be able to:
- store values in variables
- tell the difference between `str`, `int`, `float`, and `bool`
- use basic string operations
- do arithmetic
- print values clearly
- accept user input
- convert values between types

## Common beginner mistakes
- forgetting quotes around strings
- mixing strings and numbers without conversion
- assuming `input()` returns a number
- overwriting variable names accidentally
- confusing `=` with `==`
