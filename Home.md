## Learning route

1. **Fundamentals:** operating systems, networking, HTTP, APIs and Git
2. **Backend:** requests, services, storage, queues and execution
3. **Cloud and infrastructure:** AWS services, containers, serverless and infrastructure as code
4. **Delivery:** environments, packaging, CI/CD, testing and deployment
5. **AI and retrieval:** LLMs, embeddings, RAG and agents
6. **Security and reliability:** identity, access, observability and failure handling

See [[Knowledge Spine]] for a connected overview.

## How to add a concept

1. Record an unfamiliar term in [[Terms]] as an unchecked item. Research it before adding a definition to [[Glossary]].
2. Add a separate note using [[Templates/Technology Note]] when the subject needs an example, diagram or deeper explanation.
3. Replace the glossary's plain entry with an Obsidian wikilink to the detailed note once it exists.
4. Link the detailed note to its neighbors on [[Knowledge Spine]] or an appropriate topic page.
5. Keep any information specific to internal systems out of this public repository.
